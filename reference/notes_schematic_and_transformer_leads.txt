For your amp simulator, I’d treat these as two separate research targets: recovering readable circuit documentation for the four amps, and obtaining real output-transformer measurements to improve the power-amp model.

The transformer data is especially valuable because it can help move the power section beyond a static saturation curve toward more realistic load-dependent behavior. However, primary impedance, winding resistance, and leakage inductance are different parameters; one cannot reliably infer all three from a typical amp spec sheet.

### B. Which parameters matter most?

Aiken Amplification's [output-transformer technical explanation](https://www.aikenamps.com/index.php/output-transformers-explained?utm_source=chatgpt.com) distinguishes reflected impedance, primary inductance, leakage inductance, capacitance, and power handling. Those are the properties I'd prioritize for the power-stage model.&#x20;

[image](https://www.google.com/s2/favicons?domain=https://www.aikenamps.com\&sz=32)

aikenamps.com



| Parameter                          | Why your amp sim needs it                                         | Best source                         |
| ---------------------------------- | ----------------------------------------------------------------- | ----------------------------------- |
| Primary impedance \\(Z_p\\)        | Sets the reflected speaker load and affects output-stage behavior | Amp schematic or manufacturer spec  |
| Primary DC resistance \\(R_p\\)    | Models copper loss and winding voltage drop                       | Direct winding measurement          |
| Secondary DC resistance \\(R_s\\)  | Helps model losses and damping                                    | Direct winding measurement          |
| Primary inductance \\(L_p\\)       | Influences low-frequency response and core behavior               | LCR/impedance analyzer              |
| Leakage inductance \\(L\_\ell\\)   | Influences high-frequency roll-off and transient ringing          | Short-circuit inductance test       |
| Interwinding capacitance \\(C_w\\) | Influences high-frequency resonance and roll-off                  | Capacitance/impedance measurement   |
| Core saturation characteristics    | Influences low-frequency compression and distortion               | Level-dependent testing             |
| Rated power and core geometry      | Helps constrain low-frequency headroom and saturation             | Datasheet and physical measurements |

One important distinction: primary impedance is not a fixed impedance inherent to the transformer. It's the load reflected through the turns ratio. A transformer can have a nominal 2,350 Ω primary impedance while its measured DC resistance is much lower.

## 3. How I'd build a usable transformer dataset

For each transformer, store the following fields, including the test conditions and whether the value is measured, specified, or estimated.

### Suggested dataset schema

One record per transformer, with source provenance and test conditions.

```

{
  "manufacturer": "",
  "part_number": "",
  "amplifier_model": "",
  "rated_power_w": null,
  "primary_impedance_ohm": null,
  "secondary_taps_ohm": [],
  "primary_dc_resistance_ohm": null,
  "secondary_dc_resistance_ohm": null,
  "primary_inductance_h": null,
  "leakage_inductance_h": null,
  "interwinding_capacitance_f": null,
  "frequency_response": [],
  "saturation_data": [],
  "measurement_conditions": "",
  "data_source": "",
  "confidence": "unverified"
}
  
```

For a useful first version, I would not hold up development waiting for every parameter. Start with published impedance, power rating, frequency response, and winding configuration. Then add measured DC resistance, inductance, leakage, and capacitance wherever credible measurements become available.

Measurement note: leakage inductance depends on the measurement setup and which winding is shorted. Record the test frequency, shorted winding, and instrument conditions so values from different transformers can be compared meaningfully.
