# Output-transformer modeling for StarterAmp

You're right: a generic output-transformer model leaves out some of the power amp's most distinctive behavior. For StarterAmp, I'd replace it with transformer-specific electrical parameters plus a nonlinear core model, using measured transformer data wherever it is available.

One important distinction: the nominal primary impedance (for example, 3.4 kΩ plate-to-plate) is the intended reflected load, not the transformer's actual impedance at every frequency. Winding resistance, magnetizing inductance, leakage inductance, capacitance, core saturation, and the speaker load determine its real behavior.

## 3. What StarterAmp's transformer model should contain

I'd use this parameter set for each transformer profile:

| Parameter                         | Why it matters                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------ |
| Primary impedance and turns ratio | Establishes reflected speaker load and voltage/current scaling                       |
| Primary half-winding DCR          | Models copper losses, asymmetry, and voltage drop                                    |
| Secondary DCR                     | Models load-dependent loss and damping                                               |
| Magnetizing inductance            | Controls low-frequency response and contributes to saturation behavior               |
| Leakage inductance                | Affects high-frequency roll-off and phase response                                   |
| Interwinding capacitance          | Helps reproduce high-frequency resonance and roll-off                                |
| Core saturation and hysteresis    | Determines low-frequency distortion, compression, and recovery                       |
| Winding and core losses           | Shape frequency response and damping                                                 |
| Feedback takeoff and polarity     | Determines how transformer response interacts with the amplifier's negative feedback |

The primary inductance needs special care: a value measured at 1 kHz and low signal level is not necessarily valid at 50 Hz or near core saturation.

## 4. Recommended implementation plan

Stage 1 — Measured linear transformer

Implement turns ratio, winding resistance, magnetizing inductance, leakage inductance, and capacitance. Validate small-signal frequency response and phase against measured curves.

Stage 2 — Nonlinear core

Add a saturation model and frequency-dependent losses. Test with low-frequency sine waves at increasing levels, measuring harmonic distortion and compression.

Stage 3 — Amp-specific integration

Couple the transformer to the actual power-tube model, output feedback loop, and speaker/cabinet impedance. A transformer profile should not be evaluated in isolation from its circuit.

My priority for your next build: start with the Fender Twin, AC30, Marshall 50 W, Marshall 100 W, and Hiwatt profiles. Those give you several well-documented starting points. Then add Mesa/Boogie and 5150 profiles once you have trustworthy measurements or transformer datasheets for the exact variants.

The key is to make the transformer profiles genuinely different electrically—not simply assign each one a different high-frequency cutoff.
