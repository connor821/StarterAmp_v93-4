## Numbers the document gives that matter for modelling

### Specifications (p-05, p-06)
- Input: balanced bridging differential; 20k balanced / 10k unbalanced. Max input +20 dBu (0.775 V ref). Max gain 45 dB +/-1 dB. Response +/-1 dB 20 Hz to 20 kHz (test sheet: +0.5/-1 dB; -3 dB at ~55 kHz +/-10 %).
- Output floating, transformer isolated, 150 ohm minimum load, +24 dBm into 600 ohm (12.28 V rms) maximum.
- THD under 0.5 % from 50 Hz to 15 kHz in limiting with 1.1 s release (faster release raises low-frequency distortion). Test sheet: under 0.3 % at 1 dB below clip without limiting.
- S/N better than 81 dB at the threshold of limiting, 30 Hz to 15 kHz. Noise floor: under -57 dBu (30 Hz to 15.7 kHz) with input/output full; under -63 dBu with input CCW. Computed S/N: 74 dB at 4:1 (threshold -30 dBu), 80 dB at 20:1 (-24 dBu).
- Attack: under 20 us for 100 % recovery; adjustable up to 800 us. The attack control is continuous and its fully-CCW position switches the limiter OFF (disables the GR circuit).
- Release: 50 ms minimum, 1.1 s maximum (for 63 % recovery); continuous. Fastest release with the pot fully CW, slowest fully CCW (the test setup says "release pot full clockwise" for the minimum).
- Ratios: 4:1, 8:1, 12:1, 20:1. Test: 20 dB more input gives 5 / 2.5 / 1.66 / 1 dB more output (4/8/12/20), +/-20 %.
- Threshold (min limiting, input level +/-2 dB): 20:1 -24 dB, 12:1 -25 dB, 8:1 -26 dB, 4:1 -30 dB; relative output at threshold +10, +9, +8, +7 dBm (with output set for about 10 dB reserve).
- Gain check: -25 dBu 2 kHz in, both pots CW: +22 dBu +/-1 dB out (47 dB; manual spec says 45 +/-1). With the FET installed and biased (limiting off) about 1 dB less.
- CMRR: better than 60 dB typical (p-20); test: more than 70 dB at 60 Hz and 20 kHz.
- Input impedance test: 10k source drop 6.0 dB +/-0.25 (20k input). Output impedance test: 600 ohm load -0.55 dB +/-0.1; 150 ohm load -2 dB +/-0.1 (about 39 ohm).
- Power: under 10 W at 120 V; +30 V and -10 V rails; fuse 1/4 A (115 V) or 1/8 A (230 V).

### Calibration levels
- Reference 0 dBu = 0.775 V rms. Meter: 0 VU = +4 dBm output with the +4 button, +8 dBm with the +8 button (tolerance +/-0.5 dB). In GR mode the meter reads gain reduction; calibrated so 10 dB of limiting shows -10 (10 dB on the scale, "tracking within +/-1 dB").
- Q-bias setup: R81 CCW, 1 kHz 0 dB in, +4 meter mode, input up until the meter reads +1 VU, turn R81 CW until the meter drops to 0 VU (1 dB drop). The FET Q1 is then slightly in conduction. Factory test: output drops exactly 1.0 dB at +10 dBu out.
- Factory test levels: -10 dBu in, output reference +10 dBu (some tests +4 or +8 dBu); 10 dB of limiting for attack/release; 1 dB for ratio tests (3 dB for 4:1).
- JBL sheet: 0.775 V 1 kHz, input and output pots mid (marked "24"), R81 CCW, output +11 dB then R81 set to +10 dB; attack CW gives 10 dB limiting; internal meter must read -10 dB with attack CCW/ CW alternately and -4 / -8 with +4 / +8.
- Hand note: R81 wiper voltage should read -1.5 to -2 V; output stage AC voltage across the emitter resistors must be symmetrical (about 4 Vrms (?)); 12:1 meter should read -2 dB (+/-0.5), 8:1 -2.5 dB, 4:1 -4 dB when the 20:1 setting shows -1 dB at the same input (hand notes p-42).
- Gain check, hand: -25 in, +20 out (+/-2 dB), "was +21.5 dB"; clipping about +24 to +25 dB; response and distortion at +23 dBu out, 20 Hz to 20 kHz +/-1 dB, 0.3 %; CMRR about -70 dB; noise about -60 dB (in CW) and -55 dB, "was -61 dB" (?).

### Meter reference
- VU meter 0 VU = +4 dBm out (or +8 dBm in the +8 position); GR scale downward from 0, calibrated so that "10 dB of limiting" reads -10. Zero adjust R55 via hole in the front panel; tracking trimmer R54. Drift of +/-1 dB is normal.

### Frequency-dependent points
- Threshold stays at the same level at 20 Hz and 20 kHz (test p-37), so the sidechain is flat across the audio band (no sidechain filter).
- 20 Hz test: "the 20 Hz test needs to be done with the release pot in full CCW" - low-frequency distortion / ripple depends on release (rectifier ripple is filtered by the release time constant).
- Hum/ripple: +30 V ripple < 0.15 mV with load (?), -10 V ripple similar (?); line regulation under 500 mV from 100 to 140 V line.

### Not in the document (explicitly absent)
- No schematic table of Q1/Q10 type other than "URET 13-0027"; no transformer ratios; no program-dependent release description; no knee width numbers other than the remark that 4:1 has a soft knee and needs 3 dB of limiting.
